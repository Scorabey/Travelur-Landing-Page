# TRAVELUR — Travel Landing Page

A responsive landing page for TRAVELUR, a fictional independent travel-planning studio, built as a front-end portfolio piece. HTML, CSS, and vanilla JavaScript, bundled with Vite.

**[Live Demo](#)** · **[Design Reference](#)**

![TRAVELUR landing page preview](./preview.png)

## Overview

TRAVELUR is a concept brand for a travel studio that plans smaller, more personal trips instead of generic package tours. The page covers a hero section, a services/feature strip, two "About" sections with supporting video blocks, a call-to-action band, destination highlights, and a footer.

## Features

- Fully responsive layout (desktop, tablet, mobile)
- Section-by-section structure: hero, features, about, CTA, destinations, footer
- Custom copywriting for every section — no lorem ipsum
- Hover and interaction states on buttons and cards
- Semantic HTML for accessibility

## Tech Stack

- HTML5
- CSS3 (Flexbox / Grid)
- Vanilla JavaScript
- [Vite](https://vitejs.dev) — dev server and build tool

## Getting Started

Clone the repo and install dependencies:

```bash
git@github.com:Scorabey/Travelur-Landing-Page.git
cd Travelur-Landing-Page
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
